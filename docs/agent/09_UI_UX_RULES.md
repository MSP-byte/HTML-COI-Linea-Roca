# 09 — UI / UX RULES

## Estética
Tablero interno profesional tipo Looker Studio.

## Objetivo
Reducir errores operativos. Claridad antes que decoración.

## Header
Identidad, búsqueda, conexión y acciones globales.

## Sidebar
Módulos claros, sin navegación duplicada.

## KPI
Una idea por card, label inequívoco y fuente correcta.

## Tablas
Encabezados claros, scroll usable, acciones visibles y datos clave sin cortes.

## Botones
Nunca mostrar acción que no tenga listener/datos suficientes o que siempre falle.
Si no está disponible: ocultar o deshabilitar con explicación.

## Timeline
Multi-OC con chips separados y wrap. Nunca números concatenados.

## Documentos
Abrir PDF solo si resoluble. Ver en Documentos como navegación válida.

## Estados vacíos
No mostrar solo “0” si existen antecedentes documentales relevantes.

## Mobile
Conservar lectura y acciones principales. No depender de hover.

## Regla
No rediseñar un módulo completo durante un bug puntual.
