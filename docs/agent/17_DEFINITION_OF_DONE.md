# 17 — DEFINITION OF DONE

## Bug terminado cuando
- causa raíz identificada;
- reproducción confirmada;
- fix mínimo;
- test de regresión;
- suite verde;
- PR;
- CI verde;
- validación manual si corresponde;
- documentación actualizada si aplica.

## Feature terminada cuando
- requisito implementado;
- persistencia correcta;
- permisos;
- errores/estados vacíos;
- tests;
- PR;
- CI;
- validación manual.

## Supabase terminado cuando
- schema/frontend/RLS compatibles;
- migración versionada si fue autorizada;
- tests;
- rollback entendido.

## Release terminado cuando
- merge autorizado;
- main actualizado;
- deploy visible;
- smoke test;
- ramas limpias.
